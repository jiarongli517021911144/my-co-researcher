# CLI

This package exposes the Typer-based command-line interface.

## Commands

- `onboard`
- `agent`
- `gateway`
- `web`
- `status`
- `cron`

## Quick Checks

```bash
python -m coresearcher --help
python -m coresearcher status
python -m coresearcher agent -m "hello"
python -m coresearcher cron list
```
